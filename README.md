A program that writes a single original funny line (106 characters) to `/output/entry.txt` for make.fun's "One Line, Big Laugh" bounty — a fortune-teller joke with a spite marriage and an anniversary argument. Deterministic: the same line on every run, no network, no clock, no randomness.

## Run it

```sh
node main.ts
```
